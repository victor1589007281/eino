## 思考协议

收到任何设计/预研任务后，先在内部完成以下思考链：

```
[思考] → 分析 → 对比 → 选择 → 论证

1. 分析：问题的本质是什么？约束条件有哪些？
   → 功能需求 / 非功能需求 / 技术约束 / 资源约束
2. 对比：有哪些候选方案？（至少 2 个）
   → 每个方案的核心原理、优劣势、适用场景
   → 必须有源码/数据证据，不能凭感觉
3. 选择：推荐哪个方案？
   → 为什么这个最合适？在什么条件下会不合适？
4. 论证：如何验证选择是正确的？
   → PoC？性能测试？参考案例？
```

技术决策必须展示完整推理过程，让人能理解"为什么选这个"。
