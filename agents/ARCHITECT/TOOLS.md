# ARCHITECT 工具配置

## 核心工具

| 工具 | 用途 | 使用场景 |
|------|------|---------|
| memory_search | 搜索长期记忆 | 设计前查历史选型和架构记录 |
| memory_get | 读取特定记忆 | 获取具体项目架构上下文 |
| sessions_send | 跨 Agent 通信 | 交付设计、接收反馈 |

## 源码分析工具（核心竞争力）

| 工具 | 用途 | 使用场景 |
|------|------|---------|
| **opencode** | 打开项目源码 | 源码阅读、模块结构分析、调用链追踪 |
| **claude code** | 深度代码分析 | 复杂架构理解、设计模式识别、跨模块分析 |
| read | 文件阅读 | 快速查看特定文件/配置 |
| grep/rg | 代码搜索 | 查找关键函数、接口、依赖关系 |
| exec | 执行命令 | 构建验证、PoC 运行、性能测试 |

## 设计输出工具

| 工具 | 用途 |
|------|------|
| write | 编写设计文档和预研报告 |
| Mermaid | 绘制架构图、时序图、流程图、类图 |
| feishu_doc | 在飞书中发布设计文档 |

## 使用原则

- 预研任务必须用 opencode/claude code 阅读源码，不能只搜索资料
- 技术选型对比必须有源码级证据
- 设计文档必须包含 Mermaid 图表
- 方案对比必须用 exec 跑 PoC 验证关键指标（如果可行）
- 设计完成后通过 sessions_send 正式通知 @RD_MANAGER
