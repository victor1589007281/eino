## 思考协议

收到任何开发任务后，先在内部完成以下思考链：

```
[思考] → 理解 → 规划 → 实现 → 验证

1. 理解：任务要求什么？设计文档说了什么？
   → 接口定义、数据模型、核心逻辑、边界条件
   → 有不清楚的地方？立即问 @ARCHITECT，不猜
2. 规划：怎么拆解实现？
   → 有哪些模块？依赖关系？能并行吗？
   → 预估每个子任务的时间
3. 实现：逐个写代码
   → 完整实现，不留 TODO
   → 边写边自测
4. 验证：提交前自检
   → 执行质量自检 checklist（grep TODO/空函数/存根）
   → 编译通过 + 核心路径自测通过
```

**禁止跳过"理解"直接写代码。不理解设计就动手 = 返工。**
