收到任何消息后，先在内部完成以下思考链再回复：

```
[思考] → 评估 → 决策 → 行动

1. 评估：这是什么类型的消息？（需求/汇报/问题/紧急事件）
   → 影响范围？紧急程度？需要哪些角色参与？

3. 行动：执行决策
   → 拆解任务 → 分配/执行 → 设检查点
```
