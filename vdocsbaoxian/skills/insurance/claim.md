## 理赔类型

### 人身保险理赔
- **重疾理赔**: 确诊即赔、实施手术、达到状态
- **医疗理赔**: 住院医疗、门诊医疗、特殊门诊
- **身故理赔**: 疾病身故、意外身故
- **伤残理赔**: 意外伤残、疾病伤残

### 财产保险理赔
- **车险理赔**: 车损、三者、盗抢
- **家财理赔**: 火灾、水灾、盗窃

## 理赔分析框架

### 1. 保障范围确认
```
模式: 是否在保障责任范围内
检查点:
  - 保险期间
  - 保障责任
  - 保额限制
```

### 2. 免责条款检查
```
模式: 是否触发免责条款
常见免责:
  - 等待期内出险
  - 既往症
  - 故意行为
  - 违法犯罪
```

### 3. 告知义务审查
```
模式: 投保时是否如实告知
检查项:
  - 健康告知
  - 职业告知
  - 既往保险
```

### 4. 因果关系分析
```
模式: 事故与保障是否有因果关系
分析要点:
  - 近因原则
  - 多因一果
  - 一因多果
```

## 常见争议类型

### 重疾定义争议
| 争议点 | 说明 | 处理建议 |
|--------|------|---------|
| 病种认定 | 是否符合条款定义 | 对照ICD编码和条款 |
| 确诊时点 | 等待期内外 | 以确诊报告日期为准 |
| 疾病程度 | 是否达到赔付标准 | 参照医学诊断标准 |

### 医疗费用争议
| 争议点 | 说明 | 处理建议 |
|--------|------|---------|
| 合理医疗 | 是否属于合理治疗 | 参照诊疗规范 |
| 免赔额 | 计算方式 | 严格按条款计算 |
| 报销范围 | 社保内外 | 区分报销规则 |

### 如实告知争议
| 争议点 | 说明 | 处理建议 |
|--------|------|---------|
| 询问范围 | 超范围询问 | 保险法第16条限制 |
| 告知程度 | 主动告知vs被动告知 | 仅需回答询问事项 |
| 因果关系 | 未告知与出险的关系 | 无因果则需赔付 |

## 证据审查要点

### 医学证据
- 诊断证明书
- 病历资料
- 检查报告
- 手术记录
- 用药清单

### 财务证据
- 费用清单
- 发票原件
- 费用分割单

### 其他证据
- 意外事故证明
- 交通事故认定书
- 司法鉴定

## 理赔时效

| 险种类型 | 索赔时效 | 法律依据 |
|---------|---------|---------|
| 人寿保险 | 5年 | 保险法第26条 |
| 非人寿保险 | 2年 | 保险法第26条 |
