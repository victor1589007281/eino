## 产品类型

### 人身保险
- **寿险**: 定期寿险、终身寿险、两全保险
- **重疾险**: 消费型重疾、储蓄型重疾、分组重疾
- **医疗险**: 百万医疗、小额医疗、中高端医疗
- **意外险**: 综合意外、交通意外、特定意外

### 财产保险
- **车险**: 交强险、商业车险
- **家财险**: 房屋保险、家庭财产保险
- **责任险**: 雇主责任险、公众责任险

## 条款分析模式

### 保障责任分析
- 模式: `保险责任|承保范围|保障内容`
- 关键点:
  - 基本保障
  - 可选保障
  - 附加保障

### 除外责任分析
- 模式: `除外责任|免责|不负责|不承担`
- 常见除外:
  - 既往症
  - 故意行为
  - 违法犯罪
  - 战争/核辐射

### 等待期分析
- 模式: `等待期|观察期|免责期`
- 常见设置:
  - 重疾险: 90-180天
  - 医疗险: 30-60天
  - 寿险: 90-180天(疾病身故)

### 犹豫期分析
- 模式: `犹豫期|冷静期`
- 标准: 一般15-20天

### 费率因子
- 年龄: 年龄越大保费越高
- 性别: 不同险种有差异
- 健康状况: 影响核保和费率
- 职业: 高危职业加费或拒保

## 产品比较框架

### 重疾险比较
| 比较维度 | 说明 |
|---------|------|
| 重疾病种数量 | 法定28种+扩展病种 |
| 轻症保障 | 赔付次数、比例 |
| 中症保障 | 赔付次数、比例 |
| 多次赔付 | 是否分组、间隔期 |
| 身故保障 | 赔保额or退保费 |
| 保费豁免 | 投保人/被保人豁免 |

### 医疗险比较
| 比较维度 | 说明 |
|---------|------|
| 保额 | 年度限额 |
| 免赔额 | 年免赔额/单次免赔 |
| 报销比例 | 100%/90%等 |
| 就医范围 | 公立/私立/特需 |
| 续保条件 | 是否保证续保 |
| 增值服务 | 绿通、垫付等 |

## 核保要点

### 健康告知评估
1. 既往病史
2. 家族病史
3. 检查异常
4. 用药记录
5. 理赔记录

### 核保结论
- **标准体**: 正常承保
- **加费承保**: 增加保费
- **除外承保**: 特定疾病除外
- **延期**: 暂不承保
- **拒保**: 无法承保

## 理赔要点

### 理赔流程
1. 报案(及时性要求)
2. 提交材料
3. 保险公司调查
4. 核定赔付

### 常见拒赔原因
- 不在保障范围
- 等待期内出险
- 未如实告知
- 免责条款

## 搜索建议

分析保险产品时:
1. 定位产品类型
2. 提取核心条款
3. 分析保障责任
4. 识别限制条件
5. 与同类产品比较
