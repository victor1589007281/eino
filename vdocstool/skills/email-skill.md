# Email Skill 使用指南

## 概述

邮件工具提供基于意图的智能邮件搜索、阅读和管理功能，支持QQ邮箱、163邮箱、Gmail等主流邮箱。

## 工具列表

### 1. search_email_by_intent - 意图搜索邮件

基于自然语言描述搜索邮件。

**参数：**
| 参数 | 类型 | 必填 | 说明 |
|------|------|------|------|
| intent_query | string | 是 | 自然语言查询，如"查找最近的报销发票" |
| provider | string | 否 | 邮箱提供商(qq/163/126/gmail)，默认qq |
| username | string | 是 | 邮箱账号 |
| password | string | 是 | 邮箱密码/授权码 |
| folder | string | 否 | 邮件文件夹，默认INBOX |
| limit | integer | 否 | 最大结果数，默认20 |

**使用示例：**
```json
{
  "intent_query": "查找最近一周的报销发票",
  "provider": "qq",
  "username": "example@qq.com",
  "password": "授权码"
}
```

### 2. analyze_email - 分析邮件

分析单封邮件的意图和内容。

**参数：**
| 参数 | 类型 | 必填 | 说明 |
|------|------|------|------|
| provider | string | 否 | 邮箱提供商 |
| username | string | 是 | 邮箱账号 |
| password | string | 是 | 授权码 |
| folder | string | 否 | 文件夹 |
| email_uid | integer | 是 | 邮件UID |

### 3. find_attachments - 查找附件

按意图查找邮件附件。

**参数：**
| 参数 | 类型 | 必填 | 说明 |
|------|------|------|------|
| intent_query | string | 是 | 意图查询，如"查找发票附件" |
| provider | string | 否 | 邮箱提供商 |
| username | string | 是 | 邮箱账号 |
| password | string | 是 | 授权码 |
| limit | integer | 否 | 最大结果数 |

### 4. read_email - 读取邮件

读取邮件详细内容。

### 5. send_email - 发送邮件

发送新邮件。

**参数：**
| 参数 | 类型 | 必填 | 说明 |
|------|------|------|------|
| to | string | 是 | 收件人，多个用逗号分隔 |
| subject | string | 是 | 邮件主题 |
| body | string | 是 | 邮件正文 |
| is_html | boolean | 否 | 是否HTML格式 |

### 6. download_attachment - 下载附件

下载邮件附件到本地。

## 邮箱配置说明

### QQ邮箱

1. 登录 QQ邮箱网页版 (mail.qq.com)
2. 进入 **设置 -> 账户**
3. 找到 **POP3/IMAP/SMTP/Exchange/CardDAV/CalDAV服务**
4. 开启 **IMAP/SMTP服务**
5. 生成并保存**授权码**

```
连接信息:
- IMAP服务器: imap.qq.com:993 (SSL)
- SMTP服务器: smtp.qq.com:465 (SSL)
```

### 163/126邮箱

1. 登录网易邮箱网页版
2. 进入 **设置 -> POP3/SMTP/IMAP**
3. 开启 **IMAP/SMTP服务**
4. 设置**客户端授权密码**

```
连接信息 (163):
- IMAP服务器: imap.163.com:993 (SSL)
- SMTP服务器: smtp.163.com:465 (SSL)
```

### Gmail

1. 登录 Google 账户
2. 开启**两步验证**
3. 生成**应用专用密码**

```
连接信息:
- IMAP服务器: imap.gmail.com:993 (SSL)
- SMTP服务器: smtp.gmail.com:587 (STARTTLS)
```

**注意**: Gmail 在国内可能需要代理访问

## 使用最佳实践

### 1. 意图查询技巧

```
✅ 好的查询:
"查找本月的发票附件"
"搜索来自张三的报告邮件"
"找最近3天的快递通知"

❌ 避免:
"找邮件" (太泛泛)
"搜索" (没有具体意图)
```

### 2. 时间范围指定

意图分析会自动识别时间表达：
- "今天" / "昨天"
- "本周" / "本月"
- "最近N天" / "最近一周"
- "3天内" / "一个月内"

### 3. 附件搜索

```
# 按类型搜索
"查找PDF附件"
"搜索Excel表格附件"
"找图片附件"

# 按用途搜索
"查找发票附件"
"搜索报告文档"
"找会议日程文件"
```

## 安全注意事项

1. **使用授权码**：所有邮箱都应使用授权码而非登录密码
2. **敏感信息**：邮件可能包含敏感信息，注意数据安全
3. **授权码保密**：授权码应妥善保管，不要泄露
4. **定期更换**：建议定期更换授权码

## 常见问题

### Q: 连接失败怎么办？
A: 检查以下项目：
1. 邮箱是否开启了IMAP服务
2. 是否使用授权码（而非登录密码）
3. 网络是否正常（Gmail需要代理）

### Q: 搜索结果不准确？
A: 尝试：
1. 使用更具体的意图描述
2. 添加时间范围限制
3. 指定发件人或主题关键词

### Q: 如何搜索特定文件夹？
A: 使用 `folder` 参数：
- INBOX: 收件箱
- Sent: 已发送
- Drafts: 草稿箱
- 自定义文件夹名称
