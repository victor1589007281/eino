# 微信公众号风格指南

## 标题写作

### 标题长度
- 建议15-30字
- 过短缺乏信息量
- 过长在列表中显示不全

### 标题技巧
1. 使用数字增加吸引力（如：5个技巧、3步搞定）
2. 设置悬念引发好奇
3. 直接点明价值（如：干货、必看、深度）
4. 使用对比或转折

### 优秀标题示例
- "从0到1，3步搭建你的第一个微服务"
- "为什么90%的程序员都不会写文档？"
- "这5个VSCode插件，让我效率提升200%"

## 开头写作

### 黄金3秒原则
- 开头要在3秒内抓住读者
- 第一句话决定阅读意愿

### 开头技巧
1. 提出问题引发共鸣
2. 给出惊人数据或事实
3. 讲述真实故事
4. 直接说明价值

## 正文结构

### 段落规范
- 手机阅读友好：每段3-5行
- 重点加粗或变色
- 适当使用emoji增加亲和力（但不要过度）

### 小标题使用
- 长文必须有小标题
- 小标题简洁有力
- 与内容紧密相关

### 过渡句
使用过渡句增强连贯性：
- "说完了X，我们来看Y"
- "除此之外"
- "值得注意的是"

## 语气风格

### 亲切友好
- 像朋友聊天
- 使用"你"而非"您"
- 避免过于正式的用语

### 避免的用语
- "本文" → "这篇文章"/"今天"
- "笔者" → "我"
- "贵方" → "你"

## 结尾写作

### 结尾技巧
1. 总结要点
2. 呼吁行动（关注、点赞、转发）
3. 留下思考问题
4. 预告下期内容

## 示例

### 输入
本文将为贵方介绍如何使用Python进行数据分析。笔者认为这是一个很重要的技能。

### 输出
今天我来和你聊聊如何用Python进行数据分析。这项技能真的太重要了，学会之后你会发现数据处理效率直接起飞！
